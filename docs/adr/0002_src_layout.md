# ADR 0002: src layout

Date: November 5, 2026
Status: Accepted

## Context

The package can live at the root of the repository or under a `src/` directory. The choice affects how tests import the code and whether packaging mistakes are caught early.

## Decision

The package lives under `src/`, with the import path given by the package name.

## Rationale

* With the package at the root, the current directory is on the import path, so tests can import the local source tree instead of the installed package. Errors in packaging (missing files, wrong metadata) then go unnoticed until someone installs the package.
* With `src/`, tests always run against the installed package, which is what users receive.
* It is the default layout generated by `uv init --package`, so the tooling and the convention agree.

## Consequences

* Running code or tests always goes through the environment managed by uv (`uv run`), never through bare paths.
* The repository structure in the pipeline document places the package under `src/`.
